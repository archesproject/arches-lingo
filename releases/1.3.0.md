## Arches Lingo 1.3.0 Release Notes

This release is in development. Summarize the theme of the release here before publishing.

### Dependencies

```
Python:
    Upgraded:
        arches: 8.2
    Removed (now bundled with arches):
        arches-querysets
        arches-vue-components
        arches-controlled-lists

JavaScript:
    Added:
        @openvue/forms: 1.0.0
    Removed:
        @primevue/forms
        arches-controlled-lists
        arches-dev-dependencies
        arches-vue-components
```

### Changed

-   Arches Lingo now requires Arches 8.2, and with it Python 3.12+,
    PostgreSQL 16+ and Elasticsearch 9.
-   arches-querysets, arches-vue-components and arches-controlled-lists ship
    inside Arches 8.2 and are no longer installed separately. Their database
    tables and migration history are unchanged.
-   PrimeVue is replaced by OpenVue.

### Upgrading

1. Upgrade Arches to 8.2 by following the Arches 8.2.0 release notes, which
   cover the PostgreSQL, Elasticsearch and Django changes.

2. Remove the packages that are now bundled with Arches:

    ```
    pip uninstall arches-querysets arches-vue-components arches-controlled-lists
    ```

3. Upgrade the Python package:

    ```
    pip install --upgrade arches-lingo
    ```

4. Run migrations and rebuild the search indexes. Arches 8.2 renames the keys
   that resource instance relationships are stored under, which changes their
   search mapping:

    ```
    python manage.py migrate
    python manage.py es reindex_database
    ```

5. Rebuild the frontend:

    ```
    npm install
    npm run build_development
    python manage.py collectstatic
    ```

6. If you are running Arches on Apache, restart your server:

    ```
    sudo service apache2 reload
    ```
