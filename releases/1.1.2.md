## Arches Lingo 1.1.2 Release Notes

This patch release adds a management command that loads the Getty Art & Architecture Thesaurus (AAT) in a single step, fixes fixture archive portability across Arches versions, and lets Lingo editors export a thesaurus without needing membership in additional core Arches groups.

### Dependencies

```
Python:
    No changes

JavaScript:
    No changes
```

### Features

- Adds a `load_aat` management command that downloads the Getty AAT bulk export and loads it as a Lingo scheme with concepts. The load includes labels, scope notes, the hierarchy, typed associative relationships, identifiers, and source and contributor attribution. It also sets AAT concept types (concept, guide term, hierarchy name, facet) and creates any languages the export uses that are missing from the database. [#798](https://github.com/archesproject/arches-lingo/pull/798)
    ```
    python manage.py load_aat
    ```
    - Running the command again replaces the previously loaded AAT data and leaves other schemes untouched. Concepts keep the resource ids an earlier load gave them, so references to AAT concepts held elsewhere still resolve.
    - The scheme and its concepts are loaded in the `locked` lifecycle state by default. Use `--lifecycle-state` to choose a different state.
    - Loaded resources are not written to Elasticsearch by default, because indexing is the slowest part of the load. Pass `--index` to index them.
    - Use `--archive` to load from an export you have already downloaded, and `--working-directory` to keep the intermediate files so a failed run can be resumed. Run `python manage.py load_aat --help` for all options.
    - The command checks that the Lingo package and its reference data are loaded before it starts, and exits with an error if they are not.
- Adds `hierarchy name` and `facet` items to the term types controlled list and adds the AAT associative relationship types to the related properties controlled list. [#798](https://github.com/archesproject/arches-lingo/pull/798)
- Adds `--import-identifiers`, `--namespace-template`, `--lifecycle-state-id`, `--pin-resource-ids`, `--skip-indexing`, `--bypass-staging` and `--celery-byte-size-limit` options to `packages -o import_lingo_resources`. The command now exits with an error when the import fails, instead of reporting success. [#798](https://github.com/archesproject/arches-lingo/pull/798)

### Fixes

- Writes a column header row when dumping fixture archives and reads the column order back from that header when loading, so an archive created against one Arches version no longer risks copying values into the wrong columns on an installation whose model field declaration order differs. Loading now fails with a clear error if the archive contains columns that do not exist on the installation. [#765](https://github.com/archesproject/arches-lingo/pull/765)
- Adds a Lingo export endpoint so members of the Lingo Editor group can start a thesaurus export without also belonging to the core Arches Resource Editor group, and hides the export button from anonymous users. [#766](https://github.com/archesproject/arches-lingo/pull/766)

### Upgrading

1. Upgrade the Python package:
    ```
    pip install --upgrade arches-lingo
    ```

2. Run migrations:
    ```
    python manage.py migrate
    ```

3. Load the updated term types and related properties controlled lists, which `load_aat` requires:
    ```
    python manage.py packages -o import_controlled_lists -s $(python -c "import arches_lingo, os; print(os.path.dirname(arches_lingo.__file__))")/pkg/reference_data/controlled_lists/term_types.xml -ow overwrite
    python manage.py packages -o import_controlled_lists -s $(python -c "import arches_lingo, os; print(os.path.dirname(arches_lingo.__file__))")/pkg/reference_data/controlled_lists/related_properties.xml -ow overwrite
    ```

4. Rebuild the frontend:
    ```
    npm install
    npm run build_development
    python manage.py collectstatic
    ```

5. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
