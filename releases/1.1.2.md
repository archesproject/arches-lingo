## Arches Lingo 1.1.2 Release Notes

This patch release fixes fixture archive portability across Arches versions and lets Lingo editors export a thesaurus without needing membership in additional core Arches groups.

### Dependencies

```
Python:
    No changes

JavaScript:
    No changes
```

### Fixes

- Writes a column header row when dumping fixture archives and reads the column order back from that header when loading, so an archive created against one Arches version no longer risks copying values into the wrong columns on an installation whose model field declaration order differs. Loading now fails with a clear error if the archive contains columns that do not exist on the installation. [#765](https://github.com/archesproject/arches-lingo/pull/765)
- Adds a Lingo export endpoint so members of the Lingo Editor group can start a thesaurus export without also belonging to the core Arches Resource Editor group, and hides the export button from anonymous users. [#766](https://github.com/archesproject/arches-lingo/pull/766)

### Upgrading

1. Upgrade the Python package:
    ```
    pip install --upgrade arches-lingo
    ```

2. Run migrations:
    ```
    python manage.py migrate
    ```

3. Rebuild the frontend:
    ```
    npm install
    npm run build_development
    python manage.py collectstatic
    ```

4. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
